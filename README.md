# Job Tracker

A full-stack Job Tracking application built with React, Node.js, Express and MongoDB.

## Features

- User Registration & Login
- JWT Authentication
- Add Job Application
- Edit Job Application
- Delete Job Application
- Search Jobs
- Filter by Status
- Filter by Job Type
- Pagination
- Sort Applications
- Application Statistics
- Protected Routes

## Tech Stack

### Frontend
- React
- React Router
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
